# 2Ship-Android-RU

Русификация Android-порта **2 Ship 2 Harkinian** (Majora's Mask): русский текст, русская графика интерфейса и русские названия предметов.

Установить можно двумя способами: **приложением прямо на устройстве**, без компьютера, или скриптами с компьютера на Windows.

Проверено на **AYN Thor**. Должно работать на любом Android arm64, где идёт сам порт.

> **Здесь нет ни игры, ни её образа.** Репозиторий содержит только инструменты. Все файлы игры вы предоставляете сами, а сборка происходит у вас — на устройстве или на компьютере.

## Установка без компьютера

1. Со [страницы последнего релиза](../../releases/latest) скачайте на устройство **`2Ship-RU-Installer.apk`** и установите его.
2. Положите свой образ `MM_USA_v1.0.z64` в папку «Загрузки».
3. Откройте приложение **2Ship RU** и нажимайте большую кнопку.

Приложение проведёт через пять шагов: доступ к файлам → образ игры → русская версия игры → первый запуск игры → русский текст и графика. Нужен интернет: игра скачивается со страницы авторов порта.

Если 2 Ship уже установлен, приложение предложит один раз заменить его на русскую версию. Сохранения при этом не пропадают, а их копия кладётся в `2S2H_RU_backup`.

Подробнее — **[android/README.md](android/README.md)**.

## Установка с компьютера

1. Скачайте архив со [страницы релизов](../../releases) и распакуйте.
2. Подготовьте образ игры (см. [инструкцию](docs/INSTALL.md#шаг-1-подготовьте-файлы)).
3. Включите на устройстве отладку по USB и подключите его кабелем.
4. Запустите по порядку: `00_PREPARE_FILES.cmd` → `01_INSTALL.cmd`.

Подробно и по шагам — **[docs/INSTALL.md](docs/INSTALL.md)**.
Как это устроено внутри — **[docs/TECHNICAL.md](docs/TECHNICAL.md)**.

## Требования

Для приложения:

- Android-устройство на arm64, Android 8 или новее;
- интернет во время установки.

Для скриптов:

- Windows 10 или 11 (скрипты на PowerShell 5.1, он есть в системе);
- Android-устройство на arm64 с включённой отладкой по USB;
- USB-кабель;
- интернет при первом запуске: скрипт сам скачает Java, `adb` и официальный APK порта.

## Что нужно подготовить самому

Только один файл: **`MM_USA_v1.0.z64`** — ваш собственный образ Majora's Mask (NTSC-U, версия 1.0, 32 МБ).

Всё остальное делается само. Патч перевода [Zelda64Rus](http://shedevr.org.ru/zelda64rus) лежит в репозитории и в приложении и применяется к вашему образу автоматически. Русский текст, шрифт и графика интерфейса извлекаются уже из полученного русского образа.

**Про образ игры.** Мы не даём ссылок и способов поиска образов в сети: скачивание игры, которой у вас нет, нарушает авторские права, а репозитории с такими ссылками удаляют по DMCA. Используйте образ, снятый с вашего собственного картриджа. Проверить его можно по контрольным суммам из документации Zelda64Rus:

```
Размер: 33 554 432 байт
CRC32:  B428D8A7
MD5:    2A0A8ACB61538235BC1094D297FB6556
SHA-1:  D6133ACE5AFAA0882CF214CF88DABA39E266C078
```

И приложение, и скрипт `00_PREPARE_FILES.cmd` сверяют контрольные суммы сами и скажут, если файл не тот.

## Скрипты для компьютера

| Файл | Что делает |
|---|---|
| `00_PREPARE_FILES.cmd` | находит и проверяет ваш образ |
| `01_INSTALL.cmd` | полная установка с нуля |
| `02_SET_MOD_PROFILE.cmd` | переключает набор модов: `none` / `text` / `graphics` / `both` |
| `03_LOGCAT_LIVE.cmd` | запись логов во время игры |
| `04_COLLECT_LOGS.cmd` | собирает диагностику в один архив |
| `05_CHECK.cmd` | проверка состояния установки |
| `06_UPDATE_OVERLAY.cmd` | пересобрать только графику, без переустановки |
| `07_UPDATE_APP.cmd` | обновить приложение поверх, сохранив данные |

В приложении для Android то же самое делается кнопками. Исключение — запись системных логов (`03` и `04`): Android не даёт обычным приложениям читать журнал других программ, поэтому для этого по-прежнему нужен компьютер.

## Известные ограничения

Это особенности самого перевода Zelda64Rus 2.0b, а не набора:

- на экране ввода имени файла в основном латиница (Ж и И доступны — они заняли места Q и W);
- слово «Final» на счётчике дней осталось английским;
- в диалоге с двумя ответами при выборе второго варианта от первого остаётся один лишний знак. Косметика, на сохранение не влияет. Разбор — в [технической документации](docs/TECHNICAL.md#про-лишний-знак-в-диалоге-выбора).

## Проблемы и обратная связь

Сообщайте об ошибках через [Issues](../../issues).

- В приложении нажмите «Сохранить отчёт для диагностики» — архив появится в «Загрузках», приложите его.
- Со скриптами приложите логи из папки `logs`. Перед отправкой посмотрите, нет ли в них вашего имени пользователя Windows.

Если игра вылетает и без русификации (в приложении — «Без русификации», в скриптах — профиль `none`), проблема не здесь, а в самом порте: [issues апстрима](https://github.com/linkzenic/2ship2harkinian-Android/issues).

**English:** Russian localization toolkit for the Android port of 2 Ship 2 Harkinian (Zelda: Majora's Mask). Contains tooling only — no ROM, no game assets. It patches the official APK, extracts Russian text, font and UI textures from the user's own Zelda64Rus-patched ROM and builds mod files locally. Two ways to install: the on-device installer app (`2Ship-RU-Installer.apk`, no PC needed) or Windows scripts over USB debugging. See [docs/TECHNICAL.md](docs/TECHNICAL.md).
