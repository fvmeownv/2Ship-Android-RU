# 2Ship-Android-RU

Набор скриптов, который превращает Android-порт **2 Ship 2 Harkinian** (Majora's Mask) в полностью русифицированную сборку — с русским текстом, русской графикой интерфейса и русскими названиями предметов.

Проверено на **AYN Thor**. Должно работать на любом Android arm64, где идёт сам порт.

> **Здесь нет ни игры, ни её образа.** Репозиторий содержит только инструменты. Все файлы игры вы предоставляете сами, а сборка происходит у вас на компьютере.

| Названия предметов, масок, песен, локаций | английские | русские (126 текстур) |
| Титульный экран | `PRESS START` | `НАЖМИ СТАРТ` |

## Быстрый старт

1. Скачайте архив со [страницы релизов](../../releases) и распакуйте.
2. Подготовьте три файла (см. [инструкцию](docs/INSTALL.md#шаг-1-подготовьте-файлы)).
3. Включите на устройстве отладку по USB и подключите его кабелем.
4. Запустите по порядку: `00_PREPARE_FILES.cmd` → `01_INSTALL.cmd`.

Подробно и по шагам — **[docs/INSTALL.md](docs/INSTALL.md)**.
Как это устроено внутри — **[docs/TECHNICAL.md](docs/TECHNICAL.md)**.

## Требования

- Windows 10 или 11 (скрипты на PowerShell 5.1, он есть в системе);
- Android-устройство на arm64 с включённой отладкой по USB;
- USB-кабель;
- интернет при первом запуске: скрипт сам скачает Java, `adb` и официальный APK порта.

## Что нужно подготовить самому

Только один файл: **`MM_USA_v1.0.z64`** — ваш собственный образ Majora's Mask (NTSC-U, версия 1.0, 32 МБ).

Всё остальное набор делает сам. Патч перевода [Zelda64Rus](http://shedevr.org.ru/zelda64rus) лежит в репозитории (с разрешения авторов, см. [NOTICE](third_party/zelda64rus/NOTICE.md)) и применяется к вашему образу автоматически. Русский текст, шрифт и графика интерфейса извлекаются уже из полученного русского образа.

**Про образ игры.** Мы не даём ссылок и способов поиска образов в сети: скачивание игры, которой у вас нет, нарушает авторские права, а репозитории с такими ссылками удаляют по DMCA. Используйте образ, снятый с вашего собственного картриджа. Проверить его можно по контрольным суммам из документации Zelda64Rus:

```
Размер: 33 554 432 байт
CRC32:  B428D8A7
MD5:    2A0A8ACB61538235BC1094D297FB6556
SHA-1:  D6133ACE5AFAA0882CF214CF88DABA39E266C078
```

Скрипт `00_PREPARE_FILES.cmd` сверяет контрольные суммы сам и скажет, если файл не тот.

## Скрипты

| Файл | Что делает |
|---|---|
| `00_PREPARE_FILES.cmd` | находит и проверяет ваши три файла |
| `01_INSTALL.cmd` | полная установка с нуля |
| `02_SET_MOD_PROFILE.cmd` | переключает набор модов: `none` / `text` / `graphics` / `both` |
| `03_LOGCAT_LIVE.cmd` | запись логов во время игры |
| `04_COLLECT_LOGS.cmd` | собирает диагностику в один архив |
| `05_CHECK.cmd` | проверка состояния установки |
| `06_UPDATE_OVERLAY.cmd` | пересобрать только графику, без переустановки |
| `07_UPDATE_APP.cmd` | обновить приложение поверх, сохранив данные |

## Известные ограничения

Это особенности самого перевода Zelda64Rus 2.0b, а не набора:

- на экране ввода имени файла в основном латиница (Ж и И доступны — они заняли места Q и W);
- слово «Final» на счётчике дней осталось английским;
- в диалоге с двумя ответами при выборе второго варианта от первого остаётся один лишний знак. Косметика, на сохранение не влияет. Разбор — в [технической документации](docs/TECHNICAL.md#про-лишний-знак-в-диалоге-выбора).
