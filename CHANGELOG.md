# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.1.0]

Установка без компьютера. Собрано для того же APK порта **`v5.0.1-android.2`**.

### Приложение для Android

- Новое приложение **2Ship RU** (`2Ship-RU-Installer.apk`) делает на устройстве то же, что `00_PREPARE_FILES` и `01_INSTALL`: компьютер, кабель и отладка по USB не нужны.
- Пять шагов с одной кнопкой: доступ к файлам, образ игры, русская версия игры, первый запуск, русский текст и графика. Текущий шаг определяется по фактическому состоянию устройства, поэтому приложение можно закрыть на любом этапе и продолжить позже.
- Используются те же утилиты из `tools/src`, что и в версии для компьютера, без изменений.
- Образ ищется в «Загрузках» автоматически. Образы в порядке байт `.v64` и `.n64` приводятся к `.z64` сами.
- Если игра уже установлена, русская версия сначала собирается и проверяется, затем делается копия сохранений в `2S2H_RU_backup`, и только потом Android просит удалить старую версию.
- Переключение набора модов (`всё` / `только текст` / `только графика` / `без русификации`), пересборка русских файлов и переустановка игры — кнопками.
- Отчёт для диагностики одной кнопкой: журнал установщика, отчёты утилит, логи игры, список файлов.
- Чужие моды в папке `mods` не трогаются.
- Русская версия игры подписывается постоянным ключом, поэтому следующие обновления ставятся поверх. Игру, установленную скриптами с компьютера, приложение один раз заменит.
- Работа с интерфейсом с геймпада, раскладка в две колонки на широких экранах.

### Сборка

- GitHub Actions собирает приложение и прикрепляет `2Ship-RU-Installer.apk` к каждому опубликованному релизу.

### Прочее

- Скрипты для компьютера не изменились, кроме номера версии.

## [1.0.0]

Первый публичный выпуск. Собран для APK порта **`v5.0.1-android.2`** (linkzenic/2ship2harkinian-Android).

### Установка и обновление

- Установка с нуля одним скриптом: сборка APK, генерация `mm.o2r`, сборка модов, раскладка профилей.
- Обновление без переустановки: отдельно приложение (`07_UPDATE_APP`), отдельно графика (`06_UPDATE_OVERLAY`).
- Резервное копирование сохранений перед переустановкой и возврат после.
- Проверка контрольных сумм всех исходных файлов и многосигнальная проверка APK.

### Русификация

- Патч перевода Zelda64Rus включён в репозиторий, вместе с их обязательным readme. Применяется собственной утилитой (VCDIFF/xdelta3), результат сверяется по SHA-1.
- Текст диалогов и шрифт собираются из русского образа. Перед записью результата та же процедура прогоняется на чистом образе и сверяется со stock `mm.o2r` — при любом расхождении сборка прерывается.
- 281 текстура интерфейса переносится из русского образа, включая 126 названий предметов, масок, песен и точек карты из вложенных архивов YAR.
- Русский титульный экран: `НАЖМИ СТАРТ` вместо `PRESS START`.

### Диагностика

- Профили модов `none` / `text` / `graphics` / `both` для поиска причины вылетов.
- Сбор диагностики одной кнопкой: logcat, tombstone, meminfo, состояние файлов.

### От пользователя нужен один файл

Собственный образ игры. Всё остальное набор делает сам.
