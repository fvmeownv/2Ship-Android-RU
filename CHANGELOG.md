# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.0.0]

Первый публичный выпуск. Собран для APK порта **`v5.0.1-android.2`** (linkzenic/2ship2harkinian-Android).

### Установка и обновление

- Установка с нуля одним скриптом: сборка APK, генерация `mm.o2r`, сборка модов, раскладка профилей.
- Обновление без переустановки: отдельно приложение (`07_UPDATE_APP`), отдельно графика (`06_UPDATE_OVERLAY`).
- Резервное копирование сохранений перед переустановкой и возврат после.
- Проверка контрольных сумм всех исходных файлов и многосигнальная проверка APK.

### Русификация

- Патч перевода Zelda64Rus включён в репозиторий с разрешения авторов, вместе с их обязательным readme. Применяется собственной утилитой (VCDIFF/xdelta3), результат сверяется по SHA-1.
- Текст диалогов и шрифт собираются из русского образа. Перед записью результата та же процедура прогоняется на чистом образе и сверяется со stock `mm.o2r` — при любом расхождении сборка прерывается.
- 281 текстура интерфейса переносится из русского образа, включая 126 названий предметов, масок, песен и точек карты из вложенных архивов YAR.
- Русский титульный экран: `НАЖМИ СТАРТ` вместо `PRESS START`.

### Диагностика

- Профили модов `none` / `text` / `graphics` / `both` для поиска причины вылетов.
- Сбор диагностики одной кнопкой: logcat, tombstone, meminfo, состояние файлов.

### От пользователя нужен один файл

Собственный образ игры. Всё остальное набор делает сам.
