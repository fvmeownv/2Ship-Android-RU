# Приложение для Android

Приложение «2Ship RU» делает на самом устройстве то же, что скрипты `00_PREPARE_FILES` и `01_INSTALL` на компьютере. Компьютер, кабель и отладка по USB не нужны.

## Установка

1. Со [страницы последнего релиза](../../../releases/latest) скачайте на устройство `2Ship-RU-Installer.apk` и установите. Браузер попросит разрешить установку приложений — разрешите. Если Play Защита предупредит, выберите «Всё равно установить».
2. Положите свой образ `MM_USA_v1.0.z64` в папку «Загрузки».
3. Откройте приложение и нажимайте большую кнопку. Приложение проведёт через пять шагов:
   доступ к файлам → образ игры → русская версия игры → первый запуск игры → русский текст и графика.

Нужен интернет: игра скачивается со страницы авторов порта.

## Частые вопросы

**У меня уже стоит 2 Ship.** Приложение предложит заменить его на русскую версию. Сначала оно соберёт и проверит русскую версию, потом сделает копию сохранений в `/sdcard/2S2H_RU_backup`, и только после этого Android спросит, удалить ли старую. Сами сохранения лежат в `/sdcard/2S2H` и при удалении игры не пропадают.

**Игра стояла с компьютера.** Её тоже нужно будет один раз заменить: версия со скриптов подписана другим ключом. Дальше обновления ставятся поверх.

**Образ не находится.** Нажмите «Выбрать файл вручную». Подходит только Majora's Mask для США, версия 1.0, 32 МБ. Файлы `.v64` и `.n64` тоже подойдут — приложение само приведёт их к нужному формату.

**На первом запуске игра просит образ.** Выберите Download → 2S2H_MM_RU → MM_USA_v1.0.z64. Приложение положило его туда заранее и уберёт после установки.

**Можно закрыть приложение посреди установки?** Да. При следующем открытии оно само определит, что уже сделано, и покажет следующий шаг. Длинные операции лучше не прерывать: во время них приложение просит не выключать экран.

**Игра вылетает.** В разделе «Что включено в игре» выберите «Без русификации». Если вылетает и так — дело в самом порте, а не в русификации. Нажмите «Сохранить отчёт для диагностики» и приложите архив из «Загрузок» к Issue.

## Чего нет по сравнению с версией для компьютера

`03_LOGCAT_LIVE` и полноценного `04_COLLECT_LOGS`: Android не даёт обычным приложениям читать системный журнал других программ. Отчёт из приложения содержит журнал установщика, отчёты утилит, папку `2S2H/logs` (если порт её ведёт) и список файлов. Для logcat остаются скрипты для компьютера.

## Как устроено

- Утилиты те же самые: Gradle берёт исходники прямо из `tools/src`, а патч перевода — из `third_party/zelda64rus`. Приложение вызывает их `main()` и переносит вывод в свой журнал.
- `zipalign` заменён классом `ZipAligner` (несжатые файлы по 4 байта, `.so` по 16 КБ, поле 0xD935).
- `uber-apk-signer` заменён библиотекой Google `apksig`.
- `adb install/uninstall` заменены системным установщиком Android (`PackageInstaller`, `ACTION_DELETE`), `adb push/pull` — прямым доступом к `/sdcard/2S2H`.
- Раскладка файлов на устройстве та же, что у скриптов: `ru_profiles/text`, `ru_profiles/graphics` → `mods`. Чужие моды в `mods` не трогаются.

Русская версия игры подписывается постоянным ключом из `app/src/main/assets/signing`, поэтому последующие обновления ставятся поверх. Ключ открытый, как и встроенный debug-ключ `uber-apk-signer`, которым подписывает версия для компьютера. Приложение стоит скачивать только со страницы релизов этого репозитория.

Подробнее — в [docs/TECHNICAL.md](../docs/TECHNICAL.md#приложение-для-android).

## Сборка

Автоматически на GitHub Actions (`.github/workflows/build-android.yml`):

- при каждом изменении в `android/`, `tools/src/` или `third_party/` проверяется, что приложение собирается; APK лежит в артефактах запуска;
- при публикации релиза APK с номером версии из тега прикрепляется к этому релизу;
- ручной запуск (Actions → Android-установщик → Run workflow) публикует тестовую сборку в пре-релиз `android-test`.

Локально: JDK 17, Android SDK, Gradle 8.10 — `gradle assembleRelease` в папке `android`.
