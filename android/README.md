# Android-установщик

Приложение «2Ship RU» делает на самом устройстве то же, что скрипты `00_PREPARE_FILES` и `01_INSTALL` на компьютере. Компьютер, кабель и отладка по USB не нужны.

## Для пользователя

1. Скачайте `2Ship-RU-Installer.apk` со страницы релизов (релиз «Установщик для Android») прямо на устройство и установите.
2. Положите свой образ `MM_USA_v1.0.z64` в папку «Загрузки».
3. Откройте приложение и нажимайте большую кнопку. Приложение проведёт через пять шагов:
   доступ к файлам → образ игры → русская версия игры → первый запуск игры → русский текст и графика.

Если на устройстве уже стоит 2 Ship (официальный или поставленный с компьютера), приложение предложит заменить его: сначала соберёт русскую версию, сделает копию сохранений в `/sdcard/2S2H_RU_backup`, и только потом попросит удалить старую. Сами сохранения лежат в `/sdcard/2S2H` и при удалении игры не пропадают.

## Как устроено

- Утилиты те же самые: Gradle берёт исходники прямо из `tools/src`, а патч перевода — из `third_party/zelda64rus`. Приложение вызывает их `main()` и переносит вывод в свой журнал.
- `zipalign` заменён классом `ZipAligner` (несжатые файлы по 4 байта, `.so` по 16 КБ, поле 0xD935).
- `uber-apk-signer` заменён библиотекой Google `apksig`.
- `adb install/uninstall` заменены системным установщиком Android (`PackageInstaller`, `ACTION_DELETE`), `adb push/pull` — прямым доступом к `/sdcard/2S2H`.
- Раскладка файлов на устройстве та же, что у скриптов: `ru_profiles/text`, `ru_profiles/graphics` → `mods`. Чужие моды в `mods` не трогаются.

Русская версия игры подписывается постоянным ключом из `app/src/main/assets/signing`, поэтому последующие обновления ставятся поверх. Ключ открытый, как и встроенный debug-ключ `uber-apk-signer`, которым подписывает версия для ПК; приложение стоит скачивать только со страницы релизов этого репозитория.

## Чего нет по сравнению с версией для ПК

`03_LOGCAT_LIVE` и полноценный `04_COLLECT_LOGS`: Android не даёт обычным приложениям читать системный журнал других программ. Кнопка «Сохранить отчёт» собирает журнал установщика, отчёты утилит, папку `2S2H/logs` (если порт её ведёт) и список файлов. Для logcat остаются скрипты для ПК.

## Сборка

Автоматически на GitHub Actions (`.github/workflows/build-android.yml`) при каждом изменении в `android/`, `tools/src/` или `third_party/`. Готовый APK публикуется в релиз `android-test`.

Локально: JDK 17, Android SDK, Gradle 8.10 — `gradle assembleRelease` в папке `android`.
